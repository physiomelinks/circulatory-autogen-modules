Instances

An instance is a parameter set of this version (never different math), in instances/<instance>/, named by its obs_data's obs_data_name. The verification tests above run at the default instance's parameters; validation runs per instance, for whatever data the instance has. An instance without obs_data is N/A for calibration ("no calibration data in this instance") and stays usable in models; the version's Calibration column fails when no instance has calibration data. Its CUFLynx archive (make omex) holds the flattened model with the instance's parameters, its obs_data and params_for_id, and every input file including the verification config: open it in CUFLynx to investigate the instance.
